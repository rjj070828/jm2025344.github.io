# 无人机群飞行规划员 · 理论题库刷题程序

2026年度《无人机群飞行规划员》职业技能等级认定理论题库刷题系统，共 800 题。

## 题库构成

| 题型 | 题量 |
| --- | --- |
| 单项选择题 | 400 |
| 多项选择题 | 200 |
| 判断题 | 200 |
| **合计** | **800** |

## 功能

- 五种练习模式：顺序练习 / 随机练习 / 题型专练 / 考试模拟（随机 100 题 · 90 分钟倒计时）/ 错题重练
- 即时判分与答案解析，答题卡快速跳题
- 练习统计与错题本，记录保存在浏览器本地（localStorage）

## 使用

直接访问 GitHub Pages 在线地址即可刷题；也可以下载本仓库文件后双击打开 `index.html` 离线使用。
